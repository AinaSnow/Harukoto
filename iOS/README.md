# 喵扑 iOS

包含宿主 App 与自定义键盘扩充，共用 C++ 中文核心、Swift 候选排序与词库。需要含 iOS 27 SDK 的 Xcode、Python 3 与 XcodeGen。

```sh
brew install xcodegen
bash scripts/build-ios.sh
```

工程由 project.yml 生成，输出在 .build/iOS。真机安装需在 Xcode 选择自己的开发团队与可用的 Bundle ID；目前没有公开 TestFlight 或可直接安装的 IPA。

App 与键盘需要同一个 App Group 来共享设置。请用自己的开发团队注册群组，并把 `iOS/AppGroup.entitlements` 与 `iOS/SharedKeyboardSettings.swift` 内的群组识别码改成相同的值；两个 target 都需要使用有权限的描述档签名。

键盘 RequestsOpenAccess=false，输入不需要完整取用权限。个人词库保存在扩充自己的沙盒，不与 macOS 同步。已通过模拟器目标编译；真机内存、触控、无障碍与跨 App 输入仍需测试。

拼音、注音和日语模式可在喵扑 App 的键盘设置中切换；`ABC` 键切换英文，再按一次回到原模式。拼音和日语键盘可按「符号」开启符号页。展开候选可浏览和翻页，选词记忆会在本机自动累积。

注音键盘可点下方「符号」开启符号页，再点「注音」返回；中文模式下常用标点会直接显示并输入中文标点。符号页的数字和符号会先完成当前组字再输入，不会误触选词或注音按键。按住删除键可连续删除；按住空格并左右滑动可移动光标，开始移动前会完成当前组字。

在喵扑 App 的键盘设置页，可选择「双猫玻璃」或简洁玻璃、跟随系统／浅色／深色、三段玻璃强度及与 macOS 相同的六种色系；下次开启键盘时生效。App 只向共享群组写入明确修改的设置，键盘唯读，不要求「完整取用」。尚未在 App 修改的设置会沿用键盘原本的选择。选词记录仍保存在键盘自己的本机沙盒，不会放进共享群组；清除请求由键盘在下次启动时执行一次。设置与记录目前都不跨设备同步。系统的「降低透明度」和「增加对比」会提高候选列底色的不透明度。玻璃效果会受系统合成和所在 App 影响。
