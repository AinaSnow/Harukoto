# 晴词发布说明

## 2026-11-10 · alpha.10 中文排序修复

- 修复 zhidaole 被未完成的 zhi-da + ole 分段抢先，知道了恢复首选；保留未完成拼音的部分候选。新增十组普通中文真实词库回归及诊断入口。
- 已启用主题加入独立中文名称，优先于弱拼接；wuerdaha 首选乌尔达哈／烏爾達哈，日文与假名保持。主题中文繁体按词组优先转换，保留标点和长名称。
- 实机只读确认用户已安装 alpha.9、FF14 0.3.0 启用且含 xinkule，但 QQ 等进程仍加载旧 DLL；必须从托盘彻底退出并重开。安装完成提示已补充。
- 16 项 CTest 已通过；alpha.10 尚未安装。普通中文词频与生硬组合仍待专项评估，不宣称已解决全部语义问题。词库仍为 0.3.0，无需重新导入。


## 0.4.4-alpha.9（开发构建，尚未发布 Release）

- FF14 全量包 0.3.0：57,672 条物品、地名、常用定型文和职业记录，113,463 组触发，附来源与逐项排除清单。
- 增加海都／森都／沙都及谢谢、初见、辛苦了等快捷触发；有可靠读音时可单选假名，无读音时输出日文名称。
- 支持更长名称和大容量主题包。需要更新到 alpha.9 才能使用本全量包；导入后原启用状态保留，新包默认关闭。
- 自动拼音可能存在多音字误读；同一触发有多个候选时需翻页。范围、版本和已知缺口见 [全量词库说明](FF14_FULL_DICTIONARY.md)。


## 0.4.4-alpha.8（开发构建，尚未发布 Release）

- 随附 FF14 词库 0.2.0：204 个词条、431 组触发，增加制作采集、魔陶器／魔科学器、魔石、票据货币及 10 种基础恢复药。
- 例如 huifuyao → ポーション／ぽーしょん，motaqiqianghuazishen → 魔土器:自己強化／まどきじこきょうか。日文表记和假名分别选词。
- 修复定型文名称读音不完整及词条中的中文冒号被替换的问题。
- 独立词库 ZIP 可导入支持主题包的版本；0.1.1 更新至 0.2.0 保留启用状态，并支持回退。旧版解析器可能将中文冒号显示为英文冒号，alpha.8 修复此问题。
- 覆盖清单与来源校验随独立包分发；金碟币及其余 Item 尚未收录。完整列表见 [FF14 清单](FF14_DICTIONARY.md)，安装和实际游戏输入验收待执行。

## 0.4.4-alpha.7（开发构建，尚未发布 Release）

- 随附 FF14 词库 0.1.1：23 个职业与 10 个物品相关定型文术语，共 89 组拼音／英文／职业缩写触发。
- 管理窗口点击“预览 FF14 词库”即可查看和导入，默认关闭，启用后重新打开输入应用。
- 支持日文表记／假名分别选择；所有触发通过真实词库简繁双模式首屏检查。该功能输出普通文字，不生成游戏自动翻译聊天标记。
- 来源及限制见 [FF14 清单](FF14_DICTIONARY.md)。当前不包含全量具体 Item、装备、料理、技能或副本。

## 0.4.4-alpha.6（开发构建，尚未发布 Release）

- 新增图形主题词库管理，从开始菜单或输入设置打开；支持预览、导入、启停和回退，展示来源与许可。需本机 Python 3.10+ 及 tkinter。

- GUI 控件流程、导出、安装支持与布局检查通过，实际安装和跨应用操作待验收。
