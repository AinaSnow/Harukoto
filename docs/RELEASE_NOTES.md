# 喵扑 Meowpuut 0.4.3 Alpha 1

这次把 macOS、Windows、Android 收到同一个版本，主要整理「句子还没打完，候选却退回第一个字」的问题。

## 输入与词库

- 拼音、注音会保留多个可选前段。选完前半句，剩下的读音继续组字；下一个音节只打一部分时，也能继续选前面的句子。
- 中日混打保留中文前段，例如 `jinwandeyueliangkirei`。完整的混合句不再被只覆盖开头的单字挤走；注音本版仍专注中文长句。
- mimo 1.0 重新核对单字读音、繁简字形、重复数据及来源冲突。更新 McBopomofo 固定快照，保留繁体异体与不同读音；简体模式使用简体来源的词频，避免繁体同音词的权重直接盖过去。
- 上下文调整只在覆盖同一段读音的候选之间进行，避免短前段因记忆加分跳到完整长句前面。macOS、iOS 可使用光标前的短段中文，以及本机已确认的选词记忆。
- 超出组字容量时保留原始读音再继续，避免新按键无声消失。

## 各平台

- **macOS：** 修正待上屏文字在模式切换、试打页重绘和空组字时的处理；保留双猫／简洁皮肤、深浅色与玻璃强度设置。需要 Apple silicon、macOS 27+。
- **Windows：** 更新 TSF 输入服务和同版词库，加入繁简切换、标点与焦点／待送文字保护。实际系统输入法目前支持拼音，注音尚未接入。x64 软件包包含安装脚本与双猫渲染器。
- **Android：** 更新共享核心、词库与拼音／注音分段，修正换字段、光标移动及长按时的待送文字处理；调整横向和分割窗口的键盘尺寸。需要 Android 7+。
- **iOS：** 同步核心与分段修复，整理键盘尺寸、长按删除、空格移动光标和锁屏恢复。提供源代码，本次不发布 IPA 或 TestFlight。

## 下载与更新

从[本版下载页](https://github.com/Krysta1ll/Meowpuut/releases/tag/v0.4.3-alpha.1)选择平台；各文件的 SHA-256 收录于同页的 `SHA256SUMS.txt`。

macOS 首次安装可用纸箱安装盘；更新请执行其中的「安裝或更新.pkg」。保存工作、注销再登录后，到系统设置加入 Meowpuut。Windows 完整解压后执行 `Install.cmd`，完成后重新开启使用输入法的应用程序。Android 安装 APK 后到系统键盘设置启用喵扑。

**Android 0.1.0 用户：** 旧版签名私钥不在目前构建环境，本版使用新的专用发行金钥，无法直接覆盖更新。请先记下设置，再卸载旧版、安装新版；卸载会清除本机设置。新的金钥保存在本机私有目录，不包含在源代码或下载包中。

## 测试范围与还没解决的事

本轮通过 macOS 915 项冒烟检查、核心组字状态与候选分段回归，以及 iOS、Windows、Android 的可移植逻辑测试。这些测试不等同所有应用程序的实际输入；Windows、Android 尚未完成真机验收。评估样本、方法及未解问题记在[输入体验记录](INPUT_EXPERIENCE_AUDIT.md)。

长句首选率仍有改善空间，少见读音与高度歧义的句子可能需要分段选字；解码搜寻范围也可能提前排除适合上下文的词。日语以小型词表及假名转换为主，不能代替完整日语整句输入法。Windows 的 Enter、删除和光标操作与待送文字的顺序尚未全面验证；应用关闭或拒绝写入时，各平台仍可能遗失未提交文字。

macOS 软件包未经 Developer ID 签名或 Apple 公证，Windows 软件包未签名。Windows 渲染器沿用源码未变的前版公开二进制，本轮重建 TSF DLL 与词库；软件包内 `BUILD-INFO.md` 列出来源和验证范围。

# 喵扑 Meowpuut 0.4.2 Alpha 1

这次更新著重长句分段、候选排序和中日混打。

- 拼音与注音在长句尚未打完时保留可选的前段；选取后，尚未转换的读音留在组字中。
- 改善拼音中日混打的分段和候选排序，例如「今晚的月亮」后接 `kirei`。注音仍专注中文输入。
- 有日语候选时，收合列会保留一项，以小猫爪标示；展开后依候选排序浏览，不再固定放在最右边。
- 拼音组字时可按空格选取高亮候选，Shift＋Enter 输出原始字母；注音空格保留大千一声。
- 扩充词库与上下文关联，调整候选窗的长句显示，并保留双猫、简洁皮肤与玻璃强度设置。

## 安装

macOS 测试包支持 macOS 27 或更新版本的 Apple silicon Mac。首次安装可使用纸箱安装盘，更新请使用安装盘内的「安裝或更新.pkg」或单独的安装包。完成后保存工作、注销再登录，再到系统设置加入 Meowpuut。下载后可用 `SHA256SUMS.txt` 核对文件。

测试包未使用 Developer ID 签名，也未经 Apple 公证，macOS 可能阻止开启。请先读[安装说明](https://github.com/Krysta1ll/Meowpuut/blob/main/docs/INSTALL.md)。

iOS 提供源代码，尚无公开 TestFlight 或 IPA；本次候选修改尚未完成真机验证。Windows 目前提供可移植核心，尚无 TSF 输入法或安装包。长句排序、繁简字形和跨 App 兼容性仍在测试；日语以单字和假名为主，不是完整日语整句输入法。

# 喵扑 Meowpuut 0.4.1 Alpha 1

这次更新整理了候选窗、词库和几个常用按键。

- 双猫和简洁皮肤新增深浅色、六组配色与三段玻璃强度。
- 拼音可用 Shift＋空格／6／3／4／7 输入一、二、三、四声与轻声；单按 Shift 切换中英。
- 中文模式可按 Option＋斜线输入 `/`。注音的 ㄥ 与原本的问号按键保留原位。
- 改善长组字的候选窗定位，以及非美式键盘和小键盘 Enter 的处理。
- 补充日常、社群与网络用语，调整上下文和整句选词；拼音可将 `wosukini` 分成中日混合候选。
- 纸箱安装盘可用于首次安装；更新旧版请使用「安裝或更新.pkg」。

## 安装

需要 macOS 27 或更新版本，以及 Apple silicon Mac。下载安装盘或安装包，完成后请保存工作、注销再登录，再到系统设置的输入来源加入 Meowpuut。更新不会移除本机选词记忆。下载后可用 `SHA256SUMS.txt` 核对文件。

本测试包未使用 Developer ID 签名或 Apple 公证，macOS 可能阻止开启。请先读 [安装说明](https://github.com/Krysta1ll/Meowpuut/blob/main/docs/INSTALL.md)。

## 还在测试

长句排序、繁简字形及不同 App 的候选定位仍可能出错；非美式实体键盘和新的定位修复尚待更多实机测试。日语目前以单字与假名为主，尚不能完整转换日语长句。本次只提供 macOS 安装包，iOS 和 Windows 仍在开发。
