# 候选来源与冲突诊断（DICT-02a）

2026-11-20。工具 `harukoto_candidate_explain.exe`（`Windows/CandidateExplain.cpp`，逻辑在 `Windows/CandidateExplain.h`），安装包里用 `Explain.cmd` 运行。只读：不改排序、不写任何文件、不写注册表、不联网，输出只在本机控制台。

## 它做什么

按输入法的同一套代码（`windowsCandidates`、选词记忆 `selection_memory::apply`、CN-07 生成候选）和同一批文件重建一串拼音的候选，逐项说明：

- **来源**：基础词库（整词、组句、前段、非精确读音；模糊音 CN-03、简拼 CN-04、纠错 CN-05 标记）、语言证据（language-evidence.sqlite）、主题中文名（主题包名）、日语词（基础日语词表、F6 词形表、日语自定义词表 japanese-custom.tsv、主题包；拼音／英文／罗马字触发）、中日混合组句、原样字母、CN-07 生成、选词记忆、个人词（DICT-02b）。合并成一项的多个来源都列出。
- **得分组成**（核心新增 `mpn_candidate_explain`）：逐词的读音、权重、先验（语料修正，奈特）、基础分（权重/700−19+先验）、个人词频或个人词加分及按封顶规则实得的部分、与后文的衔接（搭配统计、衔接短语表、句首句尾）。组句候选的合计等于核心生成分（取同一切分时）；模糊音、纠错、简拼候选不按词计分，不拆。
- **个人数据的影响**：同时用一个不挂个人数据（无选词记忆、个人词频、个人词）的会话排一遍，显示“无个人数据时第 N 项／不在列表中”；选词记忆把哪项从第几提到第几、哪项是按整串插入的。
- **冲突**：同一文字在列表中出现多次；同一触发词在几处定义（基础日语词表、自定义、主题）；主题／自定义触发排在同读音的基础词库整词之前；个人词与基础词库同读音同文字重复；未启用的主题包也有这个触发词（启用后会出现）。提示：选词记忆的整串插入、选词记忆开关关闭、读音同时是主题触发词但基础词仍在前。
- **反查**（`--text` 或交互时 `=文字`，核心新增 `mpn_explain_text`）：文字在基础词库（读音、繁简权重、先验、是否有搭配统计）、衔接短语表、语言证据、个人词表、选词记忆、个人词频、日语词表、各主题包（含未启用）中的位置。
- **检查**（`--audit`）：个人词读音拆不成本词库音节（输入法会忽略）、个人词与词库重复、日语自定义词与主题同一触发不同文字。

## 读哪些文件

与输入法相同：程序词库默认取已注册输入法 DLL 所在目录（HKLM CLSID 的 InprocServer32），没有时取程序旁的 payload；`%LOCALAPPDATA%\Meowpuut` 下的 BaseDictionaries（已安装的基础词库快照，有则优先，`--bundled` 可忽略）、Dictionaries（CURRENT 指向的启用快照 enabled.tsv，以及同快照的 state.json 用于区分主题包和未启用的包）、japanese-custom.tsv、selection-memory.tsv／-words.tsv／-user.tsv。设置读 HKCU\Software\Meowpuut\Input（繁简、模糊音、纠错、选词记忆开关），可用参数覆盖。选词记忆日志只经 `Journal::refresh` 读，不调用会写文件的 poll／flush／compact；SQLite 以只读打开。

## 用法

```
Explain.cmd                                  交互：每行一串拼音；=文字 反查；?audit 检查；空行退出
Explain.cmd gongsi                           诊断 gongsi
Explain.cmd --all gongsi                     列出全部候选（含翻页扩展），默认前 20 项
Explain.cmd --text 公司                      反查
Explain.cmd --audit                          检查个人词和自定义词
Explain.cmd --hant --fuzzy=0x7ff --typo=0 --memory=0 --context=我们 ...   覆盖设置
```

数字模式写成 `v123`。上文默认为空，所以不含输入法按上文重排的效果（`--context` 可指定）。

## 是否随安装包

随 MSVC 安装包（ZIP 与安装器）提供：`harukoto_candidate_explain.exe` 与 `Explain.cmd` 放在包根目录，和 Diagnose.cmd 并列；安装器解压目录为 `%LOCALAPPDATA%\Meowpuut\Setup\<版本>\<随机目录>`。理由：问题多在用户本机的个人数据和主题组合上出现，开发者手里没有这些文件；工具只读、不联网、不需要 Python，约 1 MB，启动约 1 秒。`Install.ps1 -VerifyOnly` 检查有 Explain.cmd 时 exe 也在。不进入 Program Files 下的输入法目录，也不加开始菜单快捷方式（诊断工具，不是日常功能）。

## 局限

- 只解释整串输入在空上文下的候选；不模拟输入中途已选的前段（`chineseLocked`）、F6 词形面板、以词定字。
- 得分组成取最高分的切分；“实得”按该读音全部同音词的顺序估算，不受核心束宽限制。个别情况下与核心实际所走的切分不同，此时合计与生成分对不上，可据此识别。
- 主题包归属靠 state.json；state.json 无法解析时只能显示“主题包（快照）”。
- 冲突只看这串输入；全表只检查个人词和自定义触发，不扫描十万级主题触发与词库读音的全部重叠。
