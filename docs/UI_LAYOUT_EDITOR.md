# 候选窗布局可视化调整

状态：UI-01 已实现于 alpha.12；UI-02 已实现于 alpha.13；UI-03 在 alpha.14 完成首轮自动边界／键盘与当前桌面隐藏窗口检查，真实混合 DPI／远程和可读性仍待验收。更新：2026-11-10。对应 [开发计划](DEVELOPMENT_PLAN.md) UI-01／02／03。

alpha.14 修复极窄工作区宽度越界与重复适配累计缩小，首次显示前从 HWND 获取 DPI 变换；新增 192 组模拟缩放／边界检查及 1,152 个定位锚点，当前双屏工作区选择通过。预览可 Tab 聚焦后用方向键、1–7、小键盘、Home／End 改变高亮；Enter／Space 仅由预览处理，不向外触发保存。正式候选依旧鼠标穿透、不抢输入焦点，没有新增真实鼠标选词。详见 [验收记录](WINDOWS_VALIDATION.md)。

## 现状与目标

alpha.12 的 CandidateSettings.cs 提供字号 14–32、宽度 480–1000 滑块和真实预览。CandidateView.cs 为正式候选与预览共用的候选测量／渲染逻辑，CandidateWindow.xaml 共用窗口内容；CandidatePreview.cs 只提供本地样例和隔离宿主。预览用独立字号参数，不修改正式候选的静态字号，不建立输入接收窗口。

设置左右分区：左侧参数，右侧六类示例。可点选预览高亮、展开／收起日语候选；翻页和 F6 当前为固定场景演示，不执行真实输入命令。预览区按实际逻辑宽度显示，超出可视区域时滚动。默认字号 18、宽度 672 保持。恢复默认只重置布局草稿，取消或关闭不保存未提交调整。

alpha.13 新增横向自动换行／纵向列表、读音字号自动跟随或手动 10–24、候选横纵间距 0–24、左右留白 4–24、上下留白 4–20、窗口内边距 4–24。右侧拖动条与宽度同步；Tab 聚焦后左右方向键调整。紧凑／标准／宽松预设同时恢复标准字号、宽度、自动读音和横向排列，简繁与词库保持。左右参数区可滚动。

正式候选在总高度超过屏幕工作区时临时等比缩小，保证全部候选可见，不修改保存配置；预览仍显示原始逻辑尺寸。极端参数的实际可读性、混合 DPI 及定位继续纳入 UI-03，不能仅以“不超出工作区”视为完成验收。

自动验证：108 组场景／宽度／字号／展开状态对照正式渲染，尺寸、位置和选词序号一致且无候选块重叠；滑块联动、默认重置保留简繁、取消不写注册表、小窗口滚动通过。真实多屏／混合 DPI／远程及 TSF 对照仍待 UI-03 验收。

UI-02 新增 96 组预设／方向／极值参数与生产几何对照，含最小间距、最大读音字号和边距；短工作区的高度适配、拖动同步与边界、预设、布局重置和取消检查通过。临时注册表测试覆盖配置迁移、保存重新读取、损坏／未知格式／错误类型回退、拒绝写入保留旧布局及简繁恢复；不修改实际用户配置。

## 配置格式与保存边界

LayoutOptions.cs 为 GUI、生产渲染和 PS7 命令行工具共享实现。路径仍为 HKCU/Software/Meowpuut/CandidateWindow，新值 LayoutV1 为 REG_SZ，字段顺序：版本;正文大小;宽度;读音大小;横间距;纵间距;左右留白;上下留白;窗口内边距;纵向标志。默认字符串为 1;18;672;0;8;8;10;8;12;0，其中读音 0 表示自动。

读取优先使用有效 LayoutV1；无此值、损坏、字段缺失、类型错误或未知格式时回退旧 FontSize／Width，其余参数默认；有效格式中的越界整数夹到允许范围。布局单值写入，不逐项覆盖旧字段，避免读取到部分布局；保存失败保留旧值。旧字段保留供回退旧版本使用，旧版无法编辑新布局。外观命令行已改用同一序列化与校验实现，修改字号／宽度不会丢失其他字段。

繁简仍由现有输入法读取独立 TraditionalOutput 值。GUI 保存若布局写入失败，会尝试恢复本次简繁改动，恢复失败明确提示。此处是错误补偿，不是跨注册表键的崩溃原子事务；布局自身的单值发布与简繁值相互独立。

设置窗口提供参数区与预览区，预览显示组字、序号、正文、读音、来源提示、高亮和分页。示例数据在本地构造，不读取或提交用户正在输入的文字。

## 交互与配置约束

- 调参即时更新预览，未保存不写配置、不改变正在输入的候选。保存后按既有刷新时机应用，不能丢失组字或改变高亮词的身份。
- 取消放弃修改；恢复默认只重置布局草稿，仍需保存，不重置简繁开关或词库启用状态。
- 配置有明确版本和参数边界；旧注册表 FontSize／Width 可读，新字段缺省时使用当前样式。默认正文 18、宽度 672，旧用户不会因升级被自动换版式。
- 单次保存整体生效，失败保留旧配置；非法参数安全回退。预览和生产共享参数校验。
- 长词和读音独立测量、换行；没有假名时不留空读音高度。中文、日文表记和假名仍为独立候选。
- 预览不发送真实按键、不注册输入法、不自动退出其他应用。

## 验收场景

1. 拖动宽度或调整字号／间距，预览即时更新，数值与保存值一致；取消后配置未变。
2. 窄窗和大字号下显示长中文、FF14 长物品名、长读音，正文和序号不重叠，各项可区分。
3. 七个候选、第二页、F4 展开／收起、F6 活用及无假名项均可预览；实际数字键和点击选择同一项。
4. 保存、重开设置、重启渲染器后布局一致；旧配置升级保持原字号／宽度；损坏配置和保存失败可恢复。
5. 100%／125%／150%／200% 缩放、不同 DPI 双屏、工作区边缘、远程串流检查；空间不足时限制在工作区内，不裁掉当前可选项。
6. 复用 Windows/tests/CandidateLayoutTests.cs 与 test-preview.ps1 检查布局、命中和渲染，再按 WINDOWS_VALIDATION.md 记录实机结果。

## 实现入口

- Windows/CandidateSettings.cs：编辑窗口、草稿和操作按钮。
- Windows/CandidateLayout.cs：共享测量、换行和命中布局。
- Windows/CandidateWindow.xaml、GlassPreview.cs：预览宿主与生产渲染接入。
- Windows/TextService.cpp：候选传递与数字选择映射不能因布局改变；原生备用窗口需保留可读性和正确选词。

先抽取共享参数与预览组件，再增加配置字段；不另写一套只用于展示的假布局。
