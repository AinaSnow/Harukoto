# 晴词剩余开发计划

更新：2026-11-10。基线：Windows 0.4.4-alpha.11、FF14 词库 0.3.0。本文件记录当前范围与剩余任务；历史批次见 [变更记录](DEVELOPMENT_CHANGELOG.md)，实际验证边界见 [开发状态](DEVELOPMENT_STATUS.md)。本轮为计划整理，未实现新增 UI 功能。

## 已完成的基线

- Windows 安装包、简洁候选窗、字号／宽度设置、简繁输出开关、远程候选可见性；新版完整安装／卸载矩阵仍待验收。
- 基础中文 410,546 条读音记录，其中 410,379 条进入原生组词；新增日常表 272 条读音、271 个词句。短拼音候选扩展、完整输入优先于未完成分段和猜测纠错。数量不等于唯一词数或语义准确率。
- 主题包图形与命令行管理、预览、独立启停、更新、回退；FF14 固定 Item／PlaceName／Completion 全表处理，57,672 条记录、113,463 组触发，主题中文名称可选。
- 日语显式触发、表记／假名分选、活用规则编译加载及 F6 整段触发面板首版。敬语、完整整句解码和生词本尚未完成。
- alpha.11 的 17 项 CTest、词库校验及安装包预检通过；自动检查不能替代实际游戏上屏。

## 剩余任务与建议顺序

P0 优先解决输入准确性和升级可用性；P1 改善日常使用与词库质量；P2 扩展语言能力与发行。编号供 Gitea issue／PR 引用，未指定负责人，不表示已创建 issue 或正在后台开发。

## UI 布局可视化调整范围

候选窗优先，不先做通用界面设计器。建议左侧参数面板、右侧真实候选预览，下方保存／取消／恢复默认。首版默认字号仍为 18、宽度 672；用户之前选择保持大小，新功能不自动改变已有外观。

参数、迁移、预览隔离及验收场景见 [UI 布局编辑器设计](UI_LAYOUT_EDITOR.md)。UI-01 → UI-02 → UI-03 分三批交付。建议完成当前中文质量与升级诊断的首轮检查后，优先交付 UI-01。

## 协作与状态维护

- 开始任务时用编号标注提交或 PR，记录范围、负责人及验证依据；当前状态写本文，历史过程写变更记录。
- 代码完成、自动检查、实机验收、已打包、已发布分别记录；未观察的实机结果不能填完成。
- 新词保留来源／编辑依据、读音和版本，禁止用提高全部权重替代排序评估。
- Windows 为当前主线；Android 保留源码，暂未排新版本交付。Apple 平台已移除。
