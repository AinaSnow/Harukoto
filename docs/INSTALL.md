# 安装晴词 · Harukoto

当前开发重点为 Windows x64。使用 Harukoto-0.4.4-alpha.16-Setup.exe，点击“安装 / 更新”，确认 Windows 管理员授权。完成后重新打开输入应用，按 Win + 空格选择“晴词 Harukoto”。

安装向导内置 PS7，无需先配置开发环境。安装器尚未签名；构建产物及 SHA-256 位于 .build/windows/dist，尚未发布 Gitea Release。构建、日志和故障排查见 [Windows README](../Windows/README.md)。

开始菜单“晴词候选窗设置”可调整字号和宽度。可从 Windows 应用列表卸载“晴词 Harukoto 输入法”；个人词表、外观设置及旧版本文件保留。

升级兼容旧 Meowpuut 的注册标识和数据路径，详情见[品牌与兼容说明](BRAND.md)。实际 UAC 升级和卸载仍按[验收表](WINDOWS_VALIDATION.md)记录。

Android 仅保留源码和[构建说明](../Android/README.md)，未发布晴词 APK。本分支不提供 Apple 平台版本。
