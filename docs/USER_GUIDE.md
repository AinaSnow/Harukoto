# 晴词 · Harukoto Windows 操作指南

适用版本：0.4.4-alpha.22。这里描述新构建的行为；已经打开的应用需要在更新安装后重新打开，才能加载新版输入服务。

## 安装与切换

运行 Harukoto-0.4.4-alpha.22-Setup.exe，点击“安装 / 更新”，确认 Windows 管理员授权。安装完成后重新打开要输入的应用，用 Win + 空格切到“晴词 Harukoto”。新版注册在简体中文分类下，分类与实际输出繁简互相独立。

## 中文输入与选词

输入 nihao 后，在候选窗中选择“你好”。请看候选前的数字选词，序号会随词库和输入内容改变。

| 按键 | 操作 |
| --- | --- |
| 数字 1–7 | 上屏当前页对应候选 |
| 方向键、Tab／Shift + Tab | 移动候选高亮 |
| Enter | 上屏高亮候选 |
| Page Up／Page Down | 候选翻页 |
| - ／ = | 打拼音时候选上一页／下一页（同 Page Up／Page Down；下一个试用包起）；没在打拼音时照常输入 - = |
| [ ／ ] | 打拼音时上屏高亮候选的第一个字／最后一个字（以词定字，下一个试用包起）；没在打拼音时为「」 |
| Backspace | 删除输入；活用面板内先返回普通候选 |
| Esc | 取消组字；活用面板内先返回普通候选 |
| 空格 | 输出原始输入字母并加空格，不用于确认候选 |
| F4 | 展开／收起同页的普通日语罗马字候选 |
| F6 | 高亮支持活用的日语表记时，打开／关闭活用面板 |

### 模糊音（下一个试用包起，CN-03，尚未打包）

分不清平翘舌、前后鼻音时，可以在开始菜单“晴词候选窗设置”左侧的“模糊音”里勾选对应的读音对，点“保存”，下次按键即生效。共 11 对，每对单独开关，默认全部关闭：z = zh、c = ch、s = sh、n = l、f = h、r = l、an = ang、en = eng、in = ing、ian = iang、uan = uang。设置按当前 Windows 用户保存。

- 勾选 z = zh 后，输入 zongguo 也能打出“中国”；勾选 s = sh 后，sijian 首选“时间”，wosizhongguoren 首选“我是中国人”。
- 勾选后两种读音按“你听不出区别”对待：常用得多的词会排到前面，频率差不多时按你输入的读音优先。例如勾选 n = l 后，nihao 仍是“你好”第一，lihao 的前两项是“你好”“利好”；只打一个音节 zi 时，“之”排在“自、字、子”等常用字之后（本机第 10 项）。
- 只对拼写完整的音节生效。只打声母的简拼（如 zg）不做模糊替换。逐段选词时，第二页的“句首的词”“首音节单字”仍只按你输入的读音列出。
- 用模糊音选出的词不会按“词”加入个人词频（选词记忆仍会记住这串拼音选了什么）。
- 勾选的对越多，长句每次按键的计算越多；本机测量全部勾选时每键多约 0.1–0.7 毫秒，四十多个字母的长串最多约 10 毫秒。

### 简拼与混拼（下一个试用包起，CN-04，尚未打包）

不用设置，直接输入即可：

- 整词只打首字母：nh 出“你好”，zg 出“中国”，zgr 出“中国人”，bjdx 出“北京大学”。zh、ch、sh 可以当一个声母打（zhg 出“中国”），只打 z、c、s 也能代表 zh、ch、sh。
- 全拼和首字母混着打：zgren 出“中国人”，beijingdx 出“北京大学”，wobzd 出“我不知道”，womenqcf 的前两项是“我们请吃饭”“我们去吃饭”。
- 同一组首字母的词按常用程度排列（nh 的第一项是“你好”，往后是“女孩、你会、男孩、您好”等）；同一串字母里拼全的音节越多越优先。
- 拼音打全时一切照旧：nihao、zhongguo、xian 等完整拼音的候选与以前完全相同，首字母候选不会挤到它们前面。
- 边打边出：全拼后面跟着下一个字的声母时（nihaom、zhongguor、wozhidaol），第一项仍是已经打全的部分（“你好”“中国”“我知道”，选它后剩下的字母留着继续打），第二项是按首字母补全的结果（“你好吗”“中国人”“我知道了”）。
- 可以加声调或隔音符限制：z1g2 只出声调对得上的词。
- 用首字母选出的词不会按“词”加入个人词频（选词记忆仍会记住这串字母选了什么，下次同样输入时排前）；已经学过的词用首字母打时仍会靠前。模糊音不作用于首字母。
- 很长的纯首字母串每次按键的计算更多，本机测量三十个字母左右的串单键最多约 11 毫秒，六十多个字母约 13 毫秒。

### 纠错（下一个试用包起，CN-05，尚未打包）

默认开启。打拼音时手滑一处，晴词会把它读成想打的拼音：

- 相邻字母颠倒：zhogn 出“中”，nihoa 出“你好”，xiexei 出“谢谢”，womne 出“我们”，xainzai 出“现在”。
- 漏一个字母：zhonguo 出“中国”，gonzuo 出“工作”。多一个字母：nihhao 出“你好”，zhonggguo 出“中国”。按到旁边的键（元音换元音、辅音换辅音）也能纠正，但最后两个按键不算。
- 句子里也可以：wozaizhognguo 出“我在中国”，womenquchifna 出“我们去吃饭”。每个候选最多纠正一处，两处手误不会同时猜。
- 纠错候选在候选窗里文字下方的小字行标“纠错”（没有获得焦点的旧式候选框里是行尾的“[纠错]”），上屏时不带这个标记。模糊音和简拼候选不标，因为那是你选择或有意的打法；以前就有的整串纠错（按错相邻键、n／ng）也标“纠错”。
- 纠错候选只在拼音读不通时出现，排在读音完全一致的候选之后：拼音本身能读通时（如 zhonggou 能读成“中够”），读通的结果保持在前，常用的纠错词（“中国”）排在第 4 位起。打完整拼音时前几项与以前相同。
- 正在打的最后一个音节不当作手误：zhongg 仍是简拼“中国”，budin 不会被改成别的字；只打首字母的串（zhd、bkn）仍按简拼处理。打了声调或隔音符时，句中不纠错。
- 开启模糊音时，模糊读音先于纠错。
- 可以在开始菜单“晴词候选窗设置”左侧的“纠错”里取消“纠正常见手误”，点“保存”，下次按键生效。关闭后不再给出任何纠错候选，包括以前就有的整串纠错（例如按错相邻键、n／ng）。设置按当前 Windows 用户保存。
- 纠错选出的词不会按“词”加入个人词频（选词记忆仍会记住这串拼音选了什么）。
- 只纠正成常用词；句子中间纠正出的词至少两个字。
- 已知不足：拼音碰巧能读通的手误（jitian 读成“几天”、nihai 读成“你还”）不会纠正成“今天”“你好”；最后两个键里的漏打、多打（shoujhi、zhongwn）不纠正。

### 添加自己的词（下一个试用包起，DICT-02b，尚未打包）

词库里没有的人名、新词，可以自己加进去。加好后输入它的拼音，它排在第一个；在句子里也能组出来（wozhaozhangshan 出“我找张珊”），也能混着首字母打（zhangs 出“张珊”）。只打两个首字母（zs）时，它要和大量常用词竞争，通常不在第一页。

在安装包解压目录或仓库的 Windows 目录下，用 PowerShell 7 运行：

```powershell
.\manage-selection-memory.ps1 -AddWord "zhang shan" -Text 张珊                 # 添加
.\manage-selection-memory.ps1 -AddWord "zhang shan" -Text 张珊 -Traditional 張珊  # 指定繁体写法
.\manage-selection-memory.ps1 -ListWords                                       # 查看
.\manage-selection-memory.ps1 -ReviseWord zhangshan -Text 张珊 -NewText 张姗     # 修订文字（也可 -NewReading 改读音）
.\manage-selection-memory.ps1 -RemoveWord zhangshan -Text 张珊                  # 删除
.\manage-selection-memory.ps1 -ExportWords D:\my-words.tsv                     # 导出
.\manage-selection-memory.ps1 -ImportWords D:\my-words.tsv                     # 导入（合并；加 -Replace 为整表替换）
.\manage-selection-memory.ps1 -UndoWords                                       # 回退到上一次修改之前；再执行一次换回来
.\manage-selection-memory.ps1 -ClearWords                                      # 全部删除（可用 -UndoWords 撤回）
```

- 读音可以写成 `zhang shan`、`zhang'shan`、`zhangshan`、`zhang1 shan1` 或 `zhāng shān`。连写时按最少音节拆开（xian 是一个音节，想要 xi'an 请加撇号或空格），ü 写 v（lv、nve）。只能用拼音音节，不认识的音节会被拒绝并说明原因。没写声调的音节，输入时打任何声调都能匹配；写了声调的，输入时打了别的声调就不匹配。
- 同一读音、同一文字再添加一次是更新（比如补上繁体），不会出现两个。同一读音可以加几个不同的词，按添加的先后排。
- 繁体模式下显示你给的繁体写法；没给时按词库逐字转换（张珊 → 張珊）。
- 修改在各应用约 2 秒内的下一次按键时生效，不用重开应用。
- 排序：这个读音的整词列表里它排第一（词库里也有同样的词时只是提前，不会出现两次）。在句子里，它像一个较常用的词那样参与组句：能胜过逐字拼出的结果和罕见的同音词，但不会顶掉同一读音下常用的词库词；只有一个音节的词不会在句子里替换常用字（加了 shi → 式，单独打 shi 时“式”第一，但 woshi 仍是“我是”）。模糊音和纠错不作用于个人词。
- 个人词是你明确添加的词，不受选词记忆开关影响：关闭选词记忆后个人词照常可用；`-Clear` 只清除选词记录和个人词频，不动个人词，个人词用 `-ClearWords` 删除。
- 每次修改前，上一版本保存为 `selection-memory-user.previous.tsv`，`-UndoWords` 在两者间切换（只保留一个上一版本）。最多 10,000 个词；每个词最多 16 个音节、192 字节。
- 数据在 `%LOCALAPPDATA%\Meowpuut\selection-memory-user.tsv`，只在本机，卸载不会删除。格式与说明见[选词记忆](SELECTION_MEMORY.md#个人词dict-02b)。

### 标点（下一个试用包起，CN-07，尚未打包）

默认中文标点。正在打拼音时按标点键，先上屏高亮的候选，再输出标点。

| 按键 | 中文标点 | 英文标点 |
| --- | --- | --- |
| , . ; | ，。； | , . ; |
| [ ] \ | 「」、 | [ ] \ |
| / | /（不变） | / |
| '（没在打拼音时） | ‘ ’（交替） | '（打拼音时始终是音节分隔符） |
| Shift + 1、4、6、9、0 | ！￥……（） | ! $ ^ ( ) |
| Shift + - ; ' , . / | ——：“”《》？（引号交替） | _ : " < > ? |
| Shift + [ ] | 『』 | { } |
| 其他 Shift 键（@ # % & * + \| ~ 等） | 不变 | 不变 |

- 打拼音时 [ ] 不是「」，而是以词定字：例如 zhongguo 高亮“中国”时按 ] 上屏“国”。高亮的词只占前一部分拼音时，其余拼音继续组字（zhongguoren 高亮“中国”按 ] 上屏“国”，剩下 ren 可继续选）。以词定字的结果不记入选词记忆和个人词频；高亮日语、英语候选或 F6 词形时按 [ ] 不做任何事。
- `/` 一律原样输出，FF14 的 /say、/tell 等指令可以直接打；要中文问号用 Shift + /。
- Ctrl + . 切换中文／英文标点，按当前 Windows 用户保存，所有应用的下一次按键生效，重新登录后保持。英文标点下所有符号按原样输出（没在打拼音时交给应用本身处理）。
- 切换后光标附近会短暂显示“中 · 中文标点／英文标点”；打拼音时候选窗顶部在“简／繁”后显示“英文标点”；任务栏的“中”图标的提示文字也会写明。
- 开始菜单“晴词候选窗设置”左侧“标点”里可以勾选“使用英文标点”，或取消“Ctrl+. 切换中英文标点”（与其他软件的 Ctrl + . 冲突时，例如 VS Code 的快速修复）。
- Caps Lock 打开、或按住 Ctrl／Alt／Win 时，标点键照旧交给应用。
- 打拼音时按其他 Shift 符号键（@ # % 等），先上屏高亮的候选再输出该符号，不再先于拼音出现在应用里。
- 已知不足：按美式键盘布局处理；引号在每个应用里各自开合交替，不看光标前的文字，删掉一个引号后可能要多按一次才对上。

### 中英文切换（下一个试用包起，CN-07，尚未打包）

- 单独按一下 Shift（左右都可以，按下后 0.5 秒内松开，中间不按别的键）切换中文／英文。按住 Shift 打大写字母或符号、Ctrl + Shift、Alt + Shift、Shift + 鼠标点击都不会切换。
- 英文时所有按键直接交给应用，和没有输入法一样；Ctrl + . 也交给应用。Ctrl + 左 Alt + Shift + Q（繁简切换）仍然有效。
- 打拼音时切到英文，已打的字母原样上屏（和按空格一样，但不加空格）。
- 打拼音时按 Shift + 字母：已打的字母连同这个大写字母原样上屏，例如 i、Shift + P、hone、空格 得到“iPhone ”。以前这个大写字母会先于拼音出现在应用里。
- 提示：切换后光标附近短暂显示“中”或“英”（约 1 秒，不抢焦点）；任务栏语言图标旁显示“中／英”图标，点击也可切换。Windows 自带的 Ctrl + 空格 等切换也会同步。任务栏图标需要用新安装包重新安装（注册）后才出现。
- 每个应用（窗口线程）各自记住中英文，重新打开应用或重新切到晴词时为中文；不保存，重启后为中文。
- 开始菜单“晴词候选窗设置”左侧“中英文切换”可选择“左右 Shift”（默认）、“仅左 Shift”或“关闭”。
- 已知不足：按住 Shift 超过 0.5 秒再松开不切换；在别的程序里点击（不经过当前应用）无法察觉；英文时字母键由应用自行处理。

## 用拼音、英语输入日语

目前只支持已收录的明确触发词，不是任意中文或英语的自动翻译。

| 输入 | 可分别选择的日语输出 |
| --- | --- |
| riben | 日本、にほん |
| ribenyu | 日本語、にほんご |
| xuexiao | 学校、がっこう |
| chi 或 eat | 食べる、たべる |
| coffee | コーヒー |

表记与假名是两条独立候选：选择“日本”只输出日本，选择“にほん”只输出にほん。候选上方的小字仍是说明，不会上屏。已有中文同形词可能另占一项，例如中文“日本”；以候选正文为实际输出。两条日语候选在收起状态下也可直接选择。表记本身就是相同假名时不再重复增加候选。

### chi 为什么以前看不到食べる

旧排序先放六个高置信中文，再放日语罗马字 chi 对应的“血”，把“食べる”排在第 9 项。eat 没有这组竞争候选，因而更容易看到。alpha.4 将明确的拼音／英语触发候选排到普通罗马字前，并为表记／假名保留第一页位置；中文“吃”仍排在前面。

## 查看更新是否生效

排查“更新后某个应用还没变化”时，alpha.21 可使用发行 ZIP 解压目录的 Diagnose.cmd。它分别显示已发布词库和各应用实际采用版本、是否等待组字结束；详细说明见[诊断指南](WINDOWS_DIAGNOSIS.md)。诊断不记录输入内容，也不会自动关闭应用。

## 日语活用

1. 输入 chi 或 eat。
2. 用方向键或 Tab 高亮“食べる”，不要先用数字上屏；顶部出现“F6 活用”。
3. 按 F6，选择“食べます”“食べて”“食べない”等形式，用数字或 Enter 上屏。
4. F6、Esc 或退格可以返回原候选页；继续输入字母会退出活用面板并继续组字。

当前活用词包括食べる、書く、行く、有る、勉強する、来る、高い、良い、可愛い、静か，只对整个明确触发词生效。高亮中文“吃”或独立假名“たべる”时不会打开活用；请高亮日语表记“食べる”。混合句局部活用、敬语及完整日语整句转换尚未实现。

## 繁简与候选外观

alpha.18 起支持主题词库热更新，alpha.19 起支持个人日语触发词表热更新，alpha.20 起支持基础中文／查询数据库／基础日语／活用表整包热更新。所有应用使用同一机制：修改后在实际输入时后台加载，当前这段保持原候选，之后的新一段使用新词库。第一段尚未变化时，完成或 Esc 取消后再输入。失败时提示“词库更新失败，沿用旧版”，修复词表后会重试。首次升级接入层及引擎代码更新仍需彻底退出并重开各输入应用。基础词库发布暂为命令行操作，见[快照与热更新指南](BASE_DICTIONARY_SNAPSHOTS.md)；直接覆盖安装目录文件不会触发该机制。

个人词表使用 `python Windows/import-japanese-dictionary.py 你的词表.txt` 导入，整表替换之前的个人词条；需要恢复时重新导入自己保留的旧源文件。`python Windows/import-japanese-dictionary.py --clear` 清空个人触发词，不影响主题包。删除文件不会作为热更新的清空指令，以免意外丢失覆盖当前内存词表。词表格式见[日语输入说明](JAPANESE_INPUT_ROADMAP.md)。

alpha.24 起：输入法会记住你选过的候选。同一串拼音下次再输入时，选过的排在最前；一段一段选出来的句子，下次会作为整句直接出现。选错一次不要紧，再选对一次就改回来。记录只保存在本机，查看、导出、清除和关闭的方法见[选词记忆](SELECTION_MEMORY.md)。

下一个试用包起（CN-06c，尚未打包）：输入法还会按“词”记住你的选择。在一句话里选过的词（比如在 wozaigongsi 里选了“公司”），换一句话或单独输入 gongsi 时也会靠前，不必原样重打。这个加分有上限、会随时间减弱：选一次只会让它越过很接近的同音词，选得越多越靠前，但不会把罕见的词顶到第一，也不会把更长的词拆开；不再使用的词约两个月后淡出，选错一次再选对一次就抵消。它和选词记忆用同一个开关、同一个管理脚本，关闭或清除时一起生效。

alpha.23 起：整句候选都不对时，按 PageDown 到第二页可以看到句首的词和首音节的常用字，继续翻页会列出该读音的全部单字。选中其中一个后，剩余拼音继续组句，可以一段一段把句子选出来。例如 qingchashouyoujian 的首选不对时，翻页选“请”，再从 chashouyoujian 的候选里继续选。

alpha.17：按 PageDown／PageUp 翻页。页数末尾的“+”（如 1 / 3+）表示还可以继续搜索；翻到当前末页再按 PageDown，会追加候选，已有候选顺序不变。完整词典匹配不再停在初始数量限制，组合句逐步扩大搜索；搜索仍有性能边界，并不产生无限个词。

切到其他应用或输入框后，未选中的拼音、候选和活用面板会取消，回来从空输入开始。已经选择、等待系统上屏的文字仍归原输入框处理，不会跟着未选中的拼音丢弃，也不会转移到其他输入框。

开始菜单目录为“晴词 Harukoto”，内含“晴词候选窗设置”和“晴词主题词库”。alpha.17 安装时迁移旧 Meowpuut 菜单入口。

开始菜单打开晴词的候选外观设置，可以修改字号和宽度。候选自动换行。勾选“输出繁体中文”并保存后输出繁体，取消勾选输出简体；设置按当前 Windows 用户保存，下次输入按键生效。Ctrl + 左 Alt + Shift + Q 也可切换并保存相同设置。日语表记不受繁简开关影响。同一页的“模糊音”见[上文](#模糊音下一个试用包起cn-03尚未打包)。

alpha.12 的设置页右侧提供真实布局预览：调整字号／宽度会立即更新。下拉框可切换短中文、FF14 长名称、日文与假名、同形异读、第二页和 F6 活用示例；点击候选可改变示例高亮，日语示例可展开／收起。示例不代表当前词库的实际排序，也不会向应用输入文字。

预览超过右侧区域时可横向滚动，显示字号不会自动缩小。“恢复默认布局”将字号恢复 18、宽度恢复 672，保留简繁和词库设置；仍需点击“保存”才生效。“取消”或关闭窗口丢弃尚未保存的调整，不撤销此前已经保存的设置。alpha.13 支持下述布局调整。

### alpha.13 布局编辑

- 排列方向可选“横向自动换行”或“纵向列表”；每页仍是七个候选，序号不改变。
- 读音默认跟随正文缩放；取消勾选后可单独设为 10–24。正文仍为 14–32，窗口宽度 480–1000。
- 候选水平／垂直间距可设为 0–24；左右留白 4–24、上下留白 4–20；窗口内边距 4–24。
- 拖动预览右侧蓝色边条可改宽度，滑块与数值同步；Tab 聚焦边条后，左右方向键每次调整 8。
- 选择紧凑／标准／宽松后点击“应用预设”，会恢复标准字号 18、宽度 672、横向排列和自动读音，并应用该预设的间距；不改变简繁和词库。仍须点击“保存”。
- 真实候选列表高于屏幕工作区时会临时整体缩小，以显示全部七项；保存的参数不变。极大字号和留白可能因缩放而变小，可用紧凑预设减少高度。预览显示原始逻辑尺寸，使用滚动查看。

保存后下次按键应用。旧配置首次读取保持字号和宽度；保存后新布局整体持久化。布局写入失败时保留之前布局，并尝试恢复本次简繁改动；若恢复也失败，设置页会明确报错。老版本不认识新布局，回退旧版后仍使用原有 FontSize／Width。

## 常见问题

alpha.15 改善普通中文组合句排序，例如 womenmingtianjian → 我们明天见、zuduishijian → 组队时间、woduanxianle → 我断线了。启用 FF14 后，xinkule 的“辛苦了”和 zaoshanghao 的“早上好”保留首选，主题扩写及日文仍可选。FF14 词库仍为 0.3.0，无需重新导入；更新后需彻底退出并重开输入应用。儿化、部分拼音及其他同音排序仍在改进。

alpha.14 补充：预览可用 Tab 聚焦，也可点击后用方向键、1–7、小键盘、Home／End 改变示例高亮。聚焦预览时 Enter／Space 不保存设置；需要保存请点击“保存”或 Tab 移到保存按钮。正式输入仍用数字键／方向键选词，候选窗不抢输入焦点；预览点击不等于真实输入支持鼠标点击选词。

本版改善屏幕边缘和极窄工作区下的适配，连续更新不累计缩小。真实混合 DPI、远程与极小窗口下的可读性仍待进一步验收。

- 数字可以选词但看不到窗口：旧渲染器曾禁止屏幕捕获；新版支持远程串流显示。更新安装后重新打开输入应用。
- 某个拼音没有日语候选：确认词表是否收录该触发词，再检查是否运行新版。FF14 词条需要先在主题管理窗口导入并启用。
- F6 没反应：先高亮支持活用的日语表记，确认顶部出现活用提示。
- 更新后行为没变化：已打开的应用可能仍加载旧 DLL，关闭并重新打开应用再试。

自定义词表格式与导入命令见[日语路线图](JAPANESE_INPUT_ROADMAP.md)。从开始菜单打开“晴词主题词库”，或在输入设置点击“管理主题词库”，可预览、导入、启停和回退多个主题包。需要 Python 3.10+ 及 tkinter，首次打开选择 python.exe。详见[主题词库管理](DICTIONARY_PACKAGES.md)。当前随附 57,672 条 [FF14 职业与物品术语](FF14_FULL_DICTIONARY.md)，点击“预览 FF14 词库”再导入、启用。功能进度及未验收项目见[开发状态](DEVELOPMENT_STATUS.md)。
