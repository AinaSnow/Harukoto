# 选词记忆

CN-06，2026-11-12。实现位于 `Windows/SelectionMemory.h`，接入点在 `Windows/TextService.cpp`，管理脚本为 `Windows/manage-selection-memory.ps1`。从 alpha.24 起随安装包提供，默认开启。

## 行为

- **记什么**：只记你确认过的选择，即用数字键或 Enter 选中的候选，以及按标点时高亮的那一个。记录内容是“这串拼音 → 这段文字”，按简体和繁体分开。
- **怎么用**：下次输入同一串拼音时，记过的文字排到最前，最多占前三位，其余顺序不变。
- **整句**：一段一段选出来的句子，选完最后一段时把整串拼音和整句也记下来，下次直接作为第一个候选出现，即使词库本身拼不出这一句。
- **排序规则**：同一串拼音下选得多的在前，次数相同则最近选的在前。所以选错一次，再选对一次就改回来了；每条的次数最多记到 8，习惯变了也能在有限次数内翻过来。

不会记录的情况：

- 没有被选中的候选、直接按空格上屏的原始拼音、Esc 或切换窗口取消的输入。
- 按标点自动补完的后半句。只有你高亮的第一段算确认。
- F6 活用面板里选的词形。
- 上屏文字和拼音完全相同的情况。

分段选到一半就取消或切走时，已经选过的单段会保留，但不会记成整句。

## 数据在哪里

记录保存在当前 Windows 用户的 `%LOCALAPPDATA%\Meowpuut\selection-memory.tsv`，只在本机，不上传、不同步。它是纯文本，每行一条：

```text
次数<TAB>s 或 t<TAB>拼音<TAB>文字
```

`s` 为简体、`t` 为繁体。同一条可以出现多行，读取时累加。文件超过约 1 MiB 时，下一次有应用启动输入法会把它合并成每条一行；上限 4 MiB，超过后不再读取也不再写入。最多保留 20,000 条，每串拼音最多 8 种文字，超出时丢弃最旧、最少用的。

这个文件记录了你打过的词句，请按同等敏感程度对待。卸载输入法不会删除它。

## 查看、导出、清除、关闭

在安装包解压目录或仓库的 Windows 目录下，用 PowerShell 7 运行：

```powershell
.\manage-selection-memory.ps1                 # 查看状态和最近 50 条
.\manage-selection-memory.ps1 -Top 500        # 查看更多
.\manage-selection-memory.ps1 -Export D:\memory.csv
.\manage-selection-memory.ps1 -Clear          # 清除全部记录
.\manage-selection-memory.ps1 -Disable        # 关闭：不再记录，也不再调整顺序
.\manage-selection-memory.ps1 -Enable
```

开关保存在 `HKCU\Software\Meowpuut\Input` 的 `SelectionMemory`（DWORD，0 为关闭，缺省为开启），下一次按键生效。关闭不会删除已有记录。清除后，已经打开的应用会在几秒内的下一次按键时同步清空。也可以直接用文本编辑器删改这个文件。

目前只有命令行入口，设置窗口里还没有对应的开关。

## 多个应用同时输入

每个加载输入法的应用各自读这个文件，各自追加。一次完整的输入结束时追加一小段；其他应用每隔约 2 秒、在下一次按键时读取新增部分。所以在 A 应用里选过的词，在 B 应用里可能要过几秒才生效。

已知边界：

- 读写发生在输入线程上。每次只有一次很小的追加或一次增量读取，没有测过在慢速磁盘或杀毒软件拦截下的停顿。
- 合并文件时如果另一个应用恰好在追加，那次追加会留在内存里稍后重试；极端时序下可能丢失个别记录。
- 清除后如果另一个应用在被察觉之前又追加了足够多的内容，那个应用可能察觉不到清除，要等它重启。
- 密码框通常由系统禁用输入法；没有针对其他敏感输入场景做额外判断。

## 验证

- `selection_memory`：排序与封顶、每串拼音和总量上限、简繁隔离、非法内容拒绝、坏行逐行跳过；两个存储对象模拟两个进程交替写入、互相可见且不重复计数；清除、被占用时保留待写、长文件合并、超限文件不读不写；开关读取。
- `tsf_focus_cancel` 新增一段，直接调用正式的选词路径：选过一次的同音字下次居首、再选回原字即恢复、分段选出的句子下次整体居首、取消不留整句、标点自动补完只记第一段、关闭后不应用也不记录、记录可被下一个服务读到。
- `selection_memory_tool`：管理脚本在临时文件和临时注册表项上的查看、导出、开关、占用时清除。

没有验证的部分：真实应用里的实际效果、多个真实应用同时输入、输入线程上的读写耗时。评测探针不加载选词记忆，所以两套评测的数字不受影响，也不反映它的效果。实验中的独立引擎没有接入选词记忆，将来接入 TSF 时需要决定由引擎还是接入层负责这份数据。
