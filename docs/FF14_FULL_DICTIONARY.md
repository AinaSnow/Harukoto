# FF14 全量名称与定型文词库 0.3.0

更新：2026-11-10。要求晴词 **0.4.4-alpha.9 或更新版本**。本包完整处理固定来源的 Item、PlaceName、Completion 三张表，按同表行 ID 对齐中日英名称。原精选 0.2.0 保留作审核和回归基准。

合计 **57,672 条来源记录、113,463 组去重后的触发记录**。同名物品可能有不同 ID，记录数不等于唯一名称数。13,360 条记录有可用假名；其余 44,312 条仅提供日文表记，不生成猜测读音。

362 条国服物品在固定日文来源的同 ID 下没有名称；4 条地名为占位符或无有效触发；50 条 Completion 为分类标题／动态索引。每个排除 ID、原名和原因都在 full/coverage.json。不会将这些记录静默当成已翻译。

“全量”指这三个固定来源表均完整处理，不代表全游戏所有文本：任务对白、说明全文、未列在 Completion 中的全部技能／NPC 名称、后来新增版本内容仍未包括。国服固定提交为 3ba064a64e21ff62b587d886701bbe6e74d8d224（提交标记 2026.09.01.0000.0000）；日英固定提交 a67c23b00fe8cb254855d06b59845958b55d28f3 标记 7.56。两个数据版本不宣称与用户服务器完全同步。

海都／森都／沙都等输入便利别名由项目显式添加，不冒充官方名称，逐条保存在 input_aliases。一般中文名使用无声调全拼；Completion 优先使用其中文检索字段。其余名称由固定 pypinyin 0.55.0 自动转拼音，多音字可能需修订。英文去空格和标点；数字按单个数字转成中文拼音／英文单词。

正式名称和可用假名分别选择。同一触发对应多条时需翻页，不保证每个同名物品都在第一页。输出普通文字，不生成游戏自动翻译聊天标记。

## 导入与更新

1. 安装 alpha.9，重新打开输入应用；旧版无法完整读取本包的新容量和无假名词条。
2. 打开“晴词主题词库”，点击“预览 FF14 词库”，或解压独立 Harukoto-FF14-0.3.0.zip 后选择 manifest.json。
3. 导入，新用户手动启用；从 0.1.1／0.2.0 更新保留原启用状态，可回退一版。
4. 重新打开记事本或游戏，输入上述例词。管理工具仍需 Python 3.10+ 与 tkinter，日常输入不需要。

## 维护与复现

```powershell
python -m pip install -r scripts/requirements-ff14.txt
python scripts/fetch-ff14-sources.py .build/ff14-full-sources
python scripts/build-ff14-full.py .build/ff14-full-sources Resources/DictionaryPackages/ff14/catalog.json .build/ff14-full-new
```

下载脚本按固定链接和 SHA-256 校验，只保存到缓存；生成脚本离线执行，拒绝覆盖已有输出。仓库不提交源 CSV 的说明正文、图标等，只保存名称对应、简短定型表达和审计记录。

full/reviewed-source.json 使用 ff14-bulk-audit-v1，明确为程序对齐，未逐项人工复核；它与精选 catalog.json 的 verified 审核格式不同。来源摘要、数据版本、拼音工具版本和覆盖账本随独立 ZIP 分发。

测试对全部导出记录核对来源账本与触发集合，真实 C++ 加载全部记录；真实中文词库／SQLite 候选测试跨全表抽样，验证繁简模式、中文候选保留、无假名表记、升级和回退。未将抽样候选检查称为全部词条上屏验收；实际游戏内输入、跨 DPI 长词显示和大包持续使用体验仍待实机验收。
