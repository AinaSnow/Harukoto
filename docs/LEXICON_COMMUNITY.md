# 社群词条维护

喵扑的社群词条是人工整理的繁简词面、读音及编辑优先级；它们是拼音和注音共用的中文词库的一部分。优先级是排序参数，不是平台的真实使用频率。一般词语同时有社群含义时，尽量沿用既有词库，避免为圈内含义改坏日常排序。

## 更新规则

目前没有自动抓取、下载或上传词库的功能。新词先记录公开来源与日期，再由维护者核对含义、读音、繁简字形、重复词和容易混淆的日常用法，人工加入；由现有词库编译与测试流程合并、去重后，随应用版本发行。引用的文章或影片保留各自权利，不因被列为查证来源而改变其授权。

## 排序回归

同音时保留一般用法的优先次序，例如无声调的「课堂／嗑糖」、「股权／谷圈」、「梦想／梦向」、「理会／立绘」与「持股／吃谷」；明确输入注音声调仍按读音过滤。社群词仍需进入引擎前七个候选，以便展开查找。这只是初始词库的排序，个人选词记忆和不同平台的候选显示数量可能改变画面。

词库编译后执行 `python3 scripts/check-community-lexicon.py <编译资源目录>`，以真实 C++ 解码器验证拼音、注音和繁简输出，以及常见词与圈内同音词的先后；测试不需要网络。新增词汇或更新上游快照时，应同时检查日常同音词，不以社群词条数量作为质量指标。

2026-11-07 加入整句测试，覆盖日常、动漫与「一部／一步／一不」语境。以「一部动漫」「一部电影」等自然搭配改善整句，不单独提高「一部」权重，避免影响「走了一步」和「一不小心」。这些是固定回归例，不代表真实使用时的整句准确率。
