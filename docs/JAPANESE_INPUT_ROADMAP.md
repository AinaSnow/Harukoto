# Windows 日语辅助输入

全项目进度、构建验证与接手顺序见[开发状态](DEVELOPMENT_STATUS.md)。第一阶段已实现；第二至第五阶段均为规划。每阶段按“核心实现→测试→Windows 交互→实机验收”推进。

参考 [Madamada 产品说明](https://madamada.catchingnow.com/llms.txt) 和[公开自定义词表格式](https://madamada.catchingnow.com/help/custom-dictionary.md)，在喵扑内独立实现。上述页面没有提供可直接接入的引擎 SDK 或源码；本实现不包含其内置词库，不代表与该产品官方集成。

## 第一阶段：显式触发词与读音

已实现 Windows TSF 侧的单词候选、假名读音标注和本地词表导入。基础词表独立整理了 41 组触发词，沿用原有日语罗马字词库。简洁版候选窗不再显示猫爪，上方小字显示读音及「拼」或「EN」标记。同形中文与日语候选分开保留。

| 输入 | 日语候选 | 读音 |
| --- | --- | --- |
| `riben` | 日本 | にほん |
| `tushuguan` | 図書館 | としょかん |
| `jiankangbaoxian` | 健康保険 | けんこうほけん |
| `coffee` | コーヒー | こーひー |
| `schedule` | スケジュール | すけじゅーる |
| `pointcard` | ポイントカード | ぽいんとかーど |
| `xingbaogu` | エリンギ | えりんぎ（并显示杏鲍菇） |

数字键选择，F4 展开本页其他日语候选；英文触发时也保留英文原文候选。空格仍输出原始拼音／字母加空格，Enter 确认高亮候选。

### 自定义词表

保存 UTF-8 文本，例如：

```text
# 我的日语词表
店長 | てんちょう | pinyin: dianzhang
ポイントカード | english: point card
エリンギ | chinese: 杏鲍菇 | pinyin: xingbaogu
```

在仓库根目录执行：

```powershell
python Windows/import-japanese-dictionary.py C:/path/to/words.txt --check
python Windows/import-japanese-dictionary.py C:/path/to/words.txt
```

编译结果写入 `%LOCALAPPDATA%/Meowpuut/japanese-custom.tsv`，无需管理员权限。导入会替换当前用户的这一个自定义词表，因此多个主题请先合并到一份文件。校验失败时不会覆盖旧文件。重新打开使用输入法的应用后加载新词表。也可用 `--output` 导出到指定文件。

支持 `pinyin`、`english`、`chinese`、`priority`，以及同字形多读音。`pinyin`、`english` 可重复；全角分隔符、拼音声调符号、空格、连字符会规范化。含汉字的词必须显式填写平假名读音。未知属性忽略；`pos` 校验合法性，但本阶段不产生语法变形。仅有读音而没有显式触发词的自定义行不会加入索引。全部转换在本地完成。

这只是公开格式的一个子集，不是完整兼容实现。第一阶段没有任意中文翻译、自动推导所有日文汉字拼音、80 万日语词库、自动罗马字索引或完整日语整句解码。显式触发词只匹配整个输入，避免误伤中文长句排序。

## 第二阶段：动词与形容词变形

下一步引入独立词性和词干模型，覆盖一段、五段、する、来る、不规则例外及两类形容词。先实现辞书形、ます、て、た、ない、可能、被动、使役、意向、条件等，再提供 Windows 键盘可操作的候选变形面板。验收包含词干不被误改、读音与表记同步、例外词及连续选择后的剩余组字。

## 第三阶段：敬语与常用表达

加入普通／丁宁／尊敬／谦让切换，显式维护「行く」「食べる」「見る」等专门敬语。人称、亲属、公司、寒暄另建表达表；不能通过统一字符串替换假装语境正确。提供原词、读音、礼貌层级和用法提示。

## 第四阶段：日语整句与混打

为拼音、英语、罗马字建立共同分段和读音消耗模型，支持部分选词、活用形直接输入、未完成末词补全及前后文排序。以 `tianqigaii`、`coffeewonomitai` 等作为功能验收示例，同时用独立材料评估中文排序、日语自然度与逐键延迟。现有中日混打不足以代表该阶段完成。

## 第五阶段：生词本和词库管理

提供本地词库启停、导入诊断、生词读音记录、复习状态、CSV 导出及记忆开关。学习记录只来自用户确认的候选，并可查看、停用和清除。主题词库按来源与授权分别管理；同步另行设计。

## 当前验证

第一阶段使用 Python 词表校验、C++ 中文／日语同形词及多读音候选测试，以及基础触发词在真实 mimo 词库上的首屏检查。TSF 与渲染器在 Windows 本机编译。后续阶段尚未实现，不将规划功能描述为已支持。
