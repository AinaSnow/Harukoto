# 拼音候选评估

`scripts/eval-pinyin-holdout.py` 使用固定的人手编写题目，分别检查单字、词组、整句和分段。找到指定候选时，脚本也会选中它，检查上屏文字及未选部分是否保留。报告包含测试数据、核心和词库的 SHA-256。

```sh
python3 scripts/eval-pinyin-holdout.py --set development
python3 scripts/eval-pinyin-holdout.py --set validation --json
```

题目不包含与本地人工词条或上下文完整相同的目标，但来源词库仍可能包含同词或其中的片段。题目由人手挑选，同音输入往往不只一个合理答案；以下是指定目标在这批题目的名次，不是准确率，也不能代表真实用户的输入分布。

## 搜寻范围比较

在同一份开发集上，将长句搜寻宽度由 5 增至 12，可选完整整句由 12 题增至 14 题，但首屏由 12 题减至 11 题；本机长句逐键测试的 P95 约由 8 ms 增至 33 ms。因此目前保留 5。这是本机比较，不代表手机性能；需要更广的语料与真机测试，才能判定其他搜寻策略。
