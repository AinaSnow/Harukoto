# 开发变更记录

本文件记录本维护分支的开发批次；上游历史发布说明见 [RELEASE_NOTES.md](RELEASE_NOTES.md)。安装包发布和源码提交分别记录。

## 2026-11-09 · 繁体输出开关与简体中文注册

- 设置页加入“输出繁体中文”，默认关闭；设置按用户持久保存，各输入服务在下次按键读取。原快捷键同步保存同一开关，日语词形保持原样。
- Windows TSF 注册到简体中文 0804；保留原 GUID，注册成功后清理旧 0404 配置。用户语言列表只迁移晴词自己的条目，保留其他输入法和语言，卸载识别新旧配置。
- 增加隔离注册表设置测试和内存语言列表迁移测试；实际机器升级迁移和跨应用交互待验收。版本 0.4.4-alpha.2，本轮未替换用户安装。
## 2026-11-09 · 活用词表接口与后续任务

- 新增独立活用词表 v1、十条示例及编译工具，支持字段校验、稳定输出和失败保留旧文件。
- 修正可愛い的普通活用、良い的表记／读音例外和ある的形式边界，日语 Python 测试共 15 项通过。尚未接入 TSF。
- 新增按依赖与验收条件拆分的开发计划，纳入 FF14 主题词库及多包管理。FF14 当前只有规划，未收集或发布词条。
- 本轮为开发工具和文档变更，不重新发布安装包，当前安装不变。
## 2026-11-09 · 晴词品牌独立与平台收敛

- 项目正式命名为“晴词 · Harukoto”，开发版本升为 0.4.4-alpha.1；Windows 输入法列表、安装向导、设置、应用列表、安装包及文档更新显示名称。
- TSF GUID、内部文件名、数据路径和注册表键保留兼容；开始菜单设置快捷方式改名，并清理旧设置入口。MIT 原版权和第三方来源保留。
- 移除 macOS 的 Swift 实现、iOS／iPadOS 工程、Apple 资源和专用构建／打包／测试脚本；重写安装与平台说明，保留 C++ 核心、词库及 Android。
- Android 仅更新显示名称，尚未构建或发布晴词 APK。用户当前 Windows 安装没有在本轮被替换。
- 清理后的 Windows MSVC 完整构建通过，7 项 CTest、10 项日语 Python 测试、14 项安装支持检查及 9 组候选布局检查通过。

## 2026-11-09 · 日语活用规则原型

- 新增独立 Python 活用模块，显式指定词性，覆盖一段、九种五段词尾、する、来る及两类形容词；保留表记和读音同步结果。
- 加入行く、ある、いい显式例外和非法输入校验，6 项测试通过。
- 尚未接入输入法或候选面板，安装包仍对应 `9743cdc` 的安装向导与简洁候选窗。后续须扩展例外并确定词表接口，再接入 Windows。

## 2026-11-09 · EXE 安装向导与简洁候选窗

- 新增 `0.4.3-japanese.3-Setup.exe` 单文件安装向导，内置经过 SHA-256 和签名校验的官方 PS7 7.6.9，保留运行时授权文件。
- 安装成功后注册当前用户 Windows 应用列表卸载入口。卸载移除系统输入法注册和当前用户快捷方式，保留个人数据、旧版本文件和安装缓存。
- 候选窗改为简洁矩形：白底细边框、浅蓝高亮、输入内容和读音标注，默认字号 18 不变。猫形玻璃只保留为独立实验预览。
- 9 组布局检查、14 项安装支持检查、EXE 解包及内置 PS7 预检通过。新包实际 UAC 安装／卸载尚待实机验收，未替换当前安装。
- 构建方式和保留文件范围已写入 Windows README。尚未发布 Gitea Release。

## 2026-11-09 · Windows 安装可靠性

- 安装和管理员注册分别写入执行账户的本地日志。机器注册失败或新注册路径校验失败时尝试恢复旧 DLL；首次安装失败尝试清理不完整注册。恢复失败单独报告。
- 版本文件复制后校验 SHA-256；相同文件复用，不覆盖不一致或被独占的已有文件。管理员注册期间持有文件锁，旧版本目录保留。
- 新增 14 项安装检查，覆盖注册成功、恢复失败、文件共享锁及真实安装入口的预检失败日志；注册调用使用模拟，不影响当前系统输入法。
- 增加实机验收模板，明确用户配置失败不自动整体回滚，完整 UAC／TSF 恢复仍待隔离环境验证。
- 已通过源码及预构建文件校验，生成 `0.4.3-japanese.2` 本地软件包；尚未替换当前安装或发布 Release。
