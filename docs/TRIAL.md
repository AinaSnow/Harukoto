系统要求：Windows 10／11 x64，需要管理员权限安装。

## 安装

1. 双击 `Setup.exe`。因为没有签名，Windows 会拦一下：
   - 出现“Windows 已保护你的电脑”：点 **更多信息** → **仍要运行**。
   - 浏览器提示“不常下载”：选择保留文件。
   - 杀毒软件误报时，请确认 SHA-256 与上表一致后再放行。
2. 点击“安装 / 更新”，同意管理员授权（UAC）。
3. 安装完成后，**重新打开**要打字的应用（已经开着的应用不会加载新输入法）。
4. 按 **Win + 空格** 切换到“晴词 Harukoto”。

卸载：Windows 设置 → 应用 → 已安装的应用 → “晴词 Harukoto 输入法”。个人词表和设置会保留。

## 基本用法

- 拼音整句输入，空格或数字选词；`-` `=` 或方向键翻页，选到本页最后一个继续按会自动翻页。
- 单按 Shift 切换中英文；Ctrl+. 切换中英文标点。
- 开始菜单“晴词候选窗设置”：候选窗风格（晴空 Fluent／晴空胶囊）、颜色、字号、宽度、简繁、模糊音、纠错、独立引擎等。
- 更多见[用户指南](USER_GUIDE.md)。

## FF14 词库（可选）

FF14 词库包含物品、地名、技能、副本、NPC、怪物、任务、坐骑、状态以及玩家常用简称（团辅、团本、幻卡、光呆等），默认不开。

1. 开始菜单打开“晴词主题词库”（alpha.35 起内置，不需要 Python）。
2. 预览 FF14 词库 → 导入 → 启用，然后重新打开游戏。

## 这一版想请你重点试的

1. **日常打字**：聊天、浏览器、记事本、Office 各打几段话，感觉首选准不准、有没有卡顿或候选窗闪烁。
2. **新候选窗**：单行横排、两种风格和浅色／深色，看字是否清楚、位置是否跟着光标、长候选是否正常换行。
3. **独立引擎（默认开启）**：同时开几个应用来回切换打字，看是否正常、有没有丢字或要重开应用的提示。觉得有问题可以在设置里关闭“多个应用共用一个输入引擎”对比一下。
4. **游戏内**（尤其 FF14，无边框窗口）：能否打字、候选是否显示、切出切回后输入法是否还在。
5. **检查更新**：在设置最下方点“检查更新”看提示是否正常；如果安装时选了每天自动检查，下次登录 Windows 后留意有没有异常提示。
6. **FF14 词库**：不装 Python 能否导入启用；打一些 NPC、怪物、任务名和简称，看能不能出来、读音对不对。

## 遇到问题请反馈

请告诉我：

- 什么应用、做了什么操作、期望和实际看到的结果；能截图更好。
- **诊断报告**：用 ZIP 包里的 `Diagnose.cmd`（或在 Setup 安装后从 ZIP 单独解压运行）。它不记录你打过的字。把输出全部复制给我。
- 某个词排得不对：用 ZIP 里的 `Explain.cmd` 输入那段拼音，把结果发给我。

已知限制：

- 安装包未签名，每次安装都会出现上面的拦截提示。
- 以管理员身份运行的程序和开始菜单搜索等沙箱程序不接入独立引擎，改用应用内输入：打字和候选不受影响，只是这个程序会多占一份词库内存，第一次打字稍慢。
- 登录后第一次打字，后台引擎启动约 2 秒，这期间候选可能稍晚出现。
- 从 alpha.35 或更早版本升级后，已经开着的应用要重开一次；从 alpha.36 升级时，只改候选窗的部分不用重开。
- 只支持 Windows x64；没有 macOS／手机版本。
